# 🎤 ZaffaApp - Social Audio Chat Application

**ZaffaApp** هو تطبيق اجتماعي متطور يركز على الدردشة الصوتية الجماعية، بناء المجتمعات، والتفاعل الحي بين المستخدمين. تم بناء التطبيق باستخدام Flutter مع واجهة مستخدم حديثة وجذابة تدعم الوضعين الليلي والنهاري.

---

## ✅ الحالة الراهنة للمشروع (Project Status)
تم فحص المشروع بالكامل وتصحيح جميع الأخطاء البرمجية (Debugging). الكود الآن:

- **متوافق**: يدعم أحدث إصدارات Flutter (3.27+) مع استخدام الدالات الحديثة.

## ✨ مميزات المشروع (Key Features)

### 1. 🏠 الصفحة الرئيسية (Smart Home Screen)
- عرض غرف الدردشة النشطة مع حالة البث المباشر (LIVE).
- شريط تنقل سفلي (Bottom Navigation) سلس للانتقال بين الأقسام.
- أزرار وصول سريع للمتجر، الأصدقاء، الألعاب، والفعاليات.

### 2. 🎙️ غرف الدردشة الصوتية (Audio Rooms)
- واجهة تفاعلية تضم المضيف والمشاركين.
- نظام "رفع اليد" لطلب التحدث.
- نظام إرسال الهدايا التفاعلية داخل الغرفة.

### 3. 💬 نظام المحادثات (Messaging System)
- محادثات خاصة بين الأصدقاء.
- واجهة رسائل أنيقة مع دعم التوقيت وحالة القراءة.
- قائمة لإدارة جميع المحادثات الجارية.

### 4. 🛒 المتجر الافتراضي (Virtual Shop)
- شراء العملات الافتراضية بحزم مختلفة.
- دعم طرق دفع متعددة (Credit Card, PayPal, Apple Pay, Google Pay).
- واجهة شحن رصيد احترافية.

### 5. 👥 إدارة الأصدقاء (Friend Management)
- قائمة بالأصدقاء المضافين مع إمكانية حذفهم.
- قسم خاص لطلبات الصداقة الواردة (Accept/Reject).
- سهولة الوصول للملف الشخصي والمحادثات.

### 6. 📊 لوحة تحكم المسؤول (Admin Dashboard)
- إحصائيات مباشرة (عدد المستخدمين، الغرف النشطة، الإيرادات).
- مراقبة آخر المستخدمين المنضمين.
- أدوات سريعة لإدارة المستخدمين وإصدار التقارير.

### 7. 🎮 نظام الرتب والمستويات (Gamification)
- نظام مستويات (Leveling System) يعتمد على نقاط الخبرة (XP).
- أوسمة تظهر بجانب اسم المستخدم تعكس مستواه وتفاعله.

### 8. 🌗 التخصيص واللغات (Theming & Localization)
- **الوضع الليلي والنهاري**: دعم كامل للثيمات لتوفير راحة للعين.
- **تعدد اللغات**: يدعم اللغتين العربية والإنجليزية بالكامل (Localization).

---

## 🚀 التقنيات المستخدمة (Tech Stack)
- **Flutter & Dart**: الإطار الأساسي للتطبيق.
- **Easy Localization**: لإدارة اللغات.
- **Shared Preferences**: لحفظ الإعدادات المحلية وبيانات المستخدم.
- **Custom UI Components**: واجهات مصممة خصيصاً باستخدام Gradients و BoxShadows.

---

## 🛠️ تشغيل المشروع
1. تأكد من تثبيت Flutter SDK.
2. قم بتشغيل الأمر `flutter pub get` لتحميل المكتبات.
3. استخدم `flutter run` لتشغيل التطبيق على المحاكي أو الجهاز الحقيقي.
